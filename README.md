# Статус сотрудников

MVP веб-системы для контроля статусов сотрудников.

## Технологии

- Node.js
- Express
- SQLite
- better-sqlite3
- JWT
- bcrypt
- HTML
- CSS
- JavaScript

## Установка

Необходим Node.js 18+.

Откройте терминал в папке проекта:

npm install

После установки:

npm start

Откройте:

http://localhost:3000

## Возможности администратора

Администратор может:

- видеть всех сотрудников;
- искать сотрудников;
- фильтровать сотрудников;
- добавлять сотрудников;
- редактировать сотрудников;
- удалять сотрудников;
- добавлять отделы;
- создавать пользователей;
- назначать руководителей отделов.


## Возможности руководителя

Руководитель:

- видит только свой отдел;
- видит статистику своего отдела;
- может искать сотрудников;
- может фильтровать сотрудников;
- не имеет доступа к административному разделу;
- не может редактировать сотрудников.


## Безопасность

Ограничение отдела выполняется на сервере.

Руководитель не получает полный список сотрудников
с последующей фильтрацией в браузере.

API автоматически использует department_id
авторизованного руководителя.

Для production необходимо заменить JWT_SECRET
на случайную секретную строку.
